# matrix_lib

это библиотека матриц на C.
Это проект для учеников старшей школы и студентов, с помощью него вы сможете делать все основные действия с матрицами в последствие будет интерактивный тг-бот для взаимодействия с библиотекой и ее функциями.

## Cтатус

На данный момент проект находится на этапе разработки, сейчас сделаны только зародыши функций.

## Возможности

### Базовые операции
- [ ] Создание и освобождение матриц
- [] Чтение и запись матриц из файла
- [ ] Сложение
- [ ] Умножение
- [ ] Транспонирование

### Линейная алгебра
- [ ] Определитель (метод Гаусса)
- [ ] Ранг
- [ ] Решение СЛАУ методом Крамера
- [ ] Обратная матрица (метод Гаусса–Жордана)
- [ ] Общее решение СЛАУ


## Сборка

Необходимо установить: Linux || WSL

```bash
make
make test
```
Запуск нужно делать из корневой папки проекта

## Структура проекта

```
matrix_lib/
├── include/
│   └── matrix.h        # публичный API: struct Matrix, коды ошибок, прототипы
├── src/
│   ├── matrix.c        # реализация библиотеки
│   └── main.c          # консольная утилита matcalc
├── tests/
│   ├── test_matrix.c   # тесты
│   └── data/           # тестовые матрицы с известными ответами
├── Makefile
└── README.md
```

## Планы

1. **Базовая библиотека** — структура матрицы, ввод/вывод, арифметика. *(в работе)*
2. **Метод Гаусса** — определитель и ранг.
3. **Системы уравнений** — Крамер, обратная матрица, общее решение.
4. **Telegram-бот** — ядро на C, бот на Python (aiogram + ctypes), решение с шагами.
5. **Ориентация в пространстве** — матрицы поворота и кватернионы.
